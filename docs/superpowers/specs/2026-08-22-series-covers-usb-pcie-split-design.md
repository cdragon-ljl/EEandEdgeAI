# 系列封面接入与 USB/PCIe 拆分设计

## 背景

站点当前包含八个一级文章系列，其中 USB 与 PCIe 共用 `usb-pcie` 系列。项目根目录的 `covers` 文件夹新增了九张定制 PNG 封面，每张封面对应拆分后的一个一级系列，图片比例约为 2.35:1。

本次改动需要同时完成两件事：

1. 将 USB 与 PCIe 拆成独立系列、目录和公开路由。
2. 将九张系列封面接入首页系列卡片和系列目录页，同时控制加载体积并保留图片构图。

## 内容结构

拆分后站点包含九个一级系列：

- `cuda`
- `ee-system`
- `rknn`
- `riscv`
- `zephyr`
- `bsp`
- `usb`
- `pcie`
- `video-audio`

USB 系列位于 `docs/articles/usb`，包含原 `usb-01` 至 `usb-09` 共 9 篇文章，文章编号保持 1 至 9。

PCIe 系列位于 `docs/articles/pcie`，包含原 `pci-01` 至 `pci-12` 共 12 篇文章。原 4 篇 USB/PCIe 对比文章作为综合总结归入 PCIe 系列，编号调整为 13 至 16。其文件名可以保留 `usb-pcie-` 前缀，以维持文章主题辨识度；公开路由统一位于 `/pcie/`。

## 封面资源

九张原始 PNG 保留在本地 `covers` 目录，不直接进入构建产物。该目录加入 `.gitignore`，避免把约 15 MB 的源图片重复提交到仓库。

使用项目现有图片压缩工具将 PNG 转换为 WebP，部署版本写入 `public/covers`：

```text
public/covers/
├── bsp.webp
├── cuda.webp
├── ee-system.webp
├── pcie.webp
├── riscv.webp
├── rknn.webp
├── usb.webp
├── video-audio.webp
└── zephyr.webp
```

压缩不改变图片尺寸和纵横比。每个系列元数据记录封面路径、原始宽度和高度，用于浏览器预留空间并降低布局偏移。

## 页面展示

### 首页系列卡片

首页的每张系列卡片在顶部显示对应封面，图片下方保留系列标题、简介、文章数量和进入提示。

- 封面使用图片自身宽高比，约为 2.35:1。
- 图片完整显示，不使用会截掉左右内容的 16:9 强制裁切。
- 卡片继续沿用站点现有边框、阴影和悬停反馈。
- 图片设置明确的 `width`、`height` 和替代文本。
- 首屏外图片使用懒加载和异步解码。

### 系列目录页

系列目录页顶部以无裁切宽幅横幅展示封面。系列名称、标签和说明位于图片下方的独立文本区域，避免覆盖封面已有文字或主体。

横幅不使用装饰性渐变和额外浮层，不嵌套在装饰卡片中。桌面端和移动端均保持完整比例，页面随后进入侧栏目录与文章卡片列表。

### 文章详情页

文章详情页不重复显示系列封面。这样可以维持当前文档阅读密度，避免每篇文章都被同一张大图占据首屏。

## 系列元数据

`SeriesMeta` 增加封面对象：

```ts
cover: {
  src: string;
  width: number;
  height: number;
  alt: string;
}
```

`usb-pcie` 从 `SeriesId`、内容集合枚举、系列顺序和类型守卫中移除，替换为独立的 `usb` 与 `pcie`。

USB 系列定位为 USB 架构、枚举、描述符、URB、类驱动、Gadget 和 Host bring-up。PCIe 系列定位为配置空间、BAR、MMIO、中断、DMA、IOMMU、Endpoint bring-up、性能调优和跨总线比较。

## 旧链接兼容

已发布的 `/usb-pcie/` 路径需要继续可访问：

- `/usb-pcie/` 跳转到 `/usb/`。
- `/usb-pcie/usb-*` 跳转到对应 `/usb/usb-*`。
- `/usb-pcie/pci-*` 跳转到对应 `/pcie/pci-*`。
- `/usb-pcie/usb-pcie-*` 跳转到对应 `/pcie/usb-pcie-*`。

GitHub Pages 不提供服务器端重定向，因此构建静态兼容页，通过 canonical、即时 meta refresh、JavaScript `location.replace` 和可点击链接完成跳转。禁用 JavaScript时仍可通过链接进入新地址。

## 测试与验收

自动测试需要验证：

- 内容集合和类型系统只接受拆分后的九个系列。
- 首页系列顺序包含独立 USB 与 PCIe。
- USB 目录恰好有 9 篇已发布文章，编号为 1 至 9。
- PCIe 目录恰好有 16 篇已发布文章，编号为 1 至 16。
- 每个系列配置了存在的 WebP 封面及准确宽高。
- 首页卡片与系列页均渲染封面，文章详情页不渲染重复封面。
- 旧 `usb-pcie` 系列页和 25 个旧文章 URL 均生成兼容跳转页。

生产构建完成后进行桌面端和移动端视觉检查：

- 封面无拉伸、无明显裁切。
- 封面中的文字和主体完整可见。
- 九宫格卡片在常见宽度下没有文本重叠或横向滚动。
- 系列页横幅、标题和文章列表层级清晰。
- 深色模式下图片边界、正文文字和焦点状态可辨识。
- 构建产物包含 Pagefind 搜索索引和所有新路由。

## 非目标

- 不为每篇文章生成独立封面。
- 不修改文章正文内容。
- 不重新设计站点字体、全局颜色或导航结构。
- 不删除本地 PNG 源文件。
