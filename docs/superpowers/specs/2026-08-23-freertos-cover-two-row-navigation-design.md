# FreeRTOS 封面与两行导航设计

## 目标

修正 FreeRTOS 系列发布封面，并解决文章系列持续增加后桌面导航入口相互挤压、错位的问题。改动保持现有站点视觉语言，不重做页头品牌、搜索、主题切换或移动端菜单交互。

## FreeRTOS 封面

- 权威源文件固定为 `covers/freertos.png`。
- 将源文件转换为适合 GitHub Pages 的 `public/covers/freertos.webp`，保留原始画面比例，不裁切、不拉伸。
- 更新 `src/lib/series.ts` 中 FreeRTOS 封面固有尺寸为源文件的 `1923 x 818`，避免浏览器按旧比例预留空间。
- 继续沿用 `/covers/freertos.webp` 公共路径，现有系列卡片和系列页无需改调用接口。

## 桌面导航

- `xl`（1280px）及以上显示完整系列导航；更窄视口使用现有侧滑菜单，避免在临界宽度压缩文字。
- 页头采用三列结构：左侧品牌、中间系列导航、右侧工具按钮。品牌和工具按钮不参与系列换行，并在两行导航区域内垂直居中。
- 中间导航按 `SERIES_ORDER` 顺序切分，每行最多 8 个入口，最多显示两行，即支持 16 个系列。
- 当前 11 个系列排列为 `8 + 3`。每行独立居中，第二行不会靠左形成视觉失衡。
- 系列名称保持完整，不缩小到难以阅读，不使用水平滚动，也不把入口收进下拉菜单。
- 活动状态、悬停状态和下划线视觉继续沿用现有设计。

## 页面占位与移动端

- 桌面完整导航高度调整为约 96px；`SiteLayout` 的主要内容顶部占位同步从 64px 提高到桌面 96px，避免固定页头覆盖首页、系列页和文章页。
- 小于 `xl` 时页头仍为 64px，主要内容保持原有 `pt-16`。
- 移动端侧滑菜单增加垂直滚动区域和安全的视口高度约束。当系列接近 16 个时，底部搜索和 GitHub 入口仍可访问。
- 菜单按钮、遮罩层和抽屉在 `xl` 断点统一隐藏，避免 1024-1279px 同时出现完整导航和移动按钮。

## 验证

- 自动测试检查桌面导航按 8 个切分、`xl` 显示断点、两档内容顶部占位和移动菜单滚动约束。
- 封面测试检查发布文件存在、可解码、尺寸为 `1923 x 818`，并与系列元数据一致。
- 生产构建必须成功。
- 页面抽查覆盖 1440px、1280px、1024px 和 390px：导航不重叠，正文不被遮挡，移动菜单可滚动，FreeRTOS 新封面比例正确。

## 非目标

- 不重新分类或重命名系列。
- 不改变首页系列卡片结构。
- 不提交当前未跟踪的其他文章、规划文件或 `tmp/` 内容。
