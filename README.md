# EEandEdgeAI

`EEandEdgeAI` 是一个面向嵌入式工程师的技术学习站，记录从底层软件、硬件平台到边缘 AI 部署的系统化实践。

项目内容围绕“嵌入式基础 → 平台与系统 → AI 推理 → 音视频工程”展开，适合希望理解完整工程链路、持续积累实践经验的读者阅读。

## 内容概览

- **嵌入式知识体系**：C/C++、Rust、MicroPython、编译与链接、启动流程、中断、DMA、RTOS 以及常见嵌入式工程方法。
- **CUDA 与 AI Infra**：GPU 执行模型、线程组织、内存层次、CUDA Kernel、性能分析、深度学习框架、推理优化与 AI 编译器。
- **RKNN 边缘 AI**：RV1126 平台、模型转换、量化、算子与精度问题、板端推理、YOLO 后处理、摄像头 NPU 流水线和性能调优。
- **Zephyr RTOS**：开发环境、Hello World、Kconfig、构建系统与 Devicetree 等嵌入式操作系统基础。
- **Linux BSP**：启动流程、SDK、镜像与烧录、串口、原理图、仪器调试和板级问题定位。
- **音视频与多媒体**：采样、YUV/RAW、摄像头、MIPI CSI、ISP/3A、RKMedia、编解码、FFmpeg、GStreamer、网络流媒体与音视频同步。

文章中的代码、流程图、架构图和公式用于解释技术原理与工程实践，重点关注从概念理解到真实设备落地之间的联系。
